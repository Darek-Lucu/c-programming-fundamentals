# 04 Functions

This folder contains introductory C programming exercises organized by topic.

Each `.c` file is a separate program with its own `main()` function. Compile and run one file at a time.

## Compile

```bash
gcc filename.c -o program
```

On Windows:

```bash
gcc filename.c -o program.exe
program.exe
```

The exercises are intended for practice. Review the code, test it with different inputs, and make sure you understand each solution.
